# Contribution guidance

The code license is MIT. Keep changes limited to runnable code, synthetic fixtures, tests, and reader technical documentation. Preserve failure results; add meaningful tests for changed authority, persistence, and recovery behavior. Never add personal data, manuscript text, covers, retailer files, model weights, private paths, credentials, or production access.

Run the standard-library test suite and rehearsals on Python3.12. Explain changed behavior and supply a reproducible example. New dependencies need a license and compatibility review. Keep existing edition tags and published release artifacts unchanged; use a new version for corrections.
