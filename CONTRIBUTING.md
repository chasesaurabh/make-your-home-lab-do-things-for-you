# Contribution guidance

The approved code license is MIT. Keep changes limited to runnable code, synthetic fixtures, tests, and reader technical documentation. Preserve failure results; add meaningful tests for changed authority, persistence, and recovery behavior. Never add personal data, manuscript text, covers, retailer files, model weights, private paths, credentials, or production access.

Run the standard-library test suite and demo on the declared Python version. New dependencies require version, license, vulnerability, and reproducibility review. No proposed contribution is a claim that the book or repository has passed its final reviews.
